# デジタル掲示板

バージョン 0.1.0

工場などの「本日の作業内容」ホワイトボードの代わりに、大型のタッチモニタ（と社内LANの他のPC）で、本日の作業予定・連絡事項・今週の休日出勤予定・災害事例の自動再生・文書閲覧を行うWebアプリです。

## 入手のしかたと説明書

- **使うだけの方**は、このページ右側の「Releases」から、いちばん新しい版の `digital-bulletin-board-v0.1.0.zip` をダウンロードします（「Source code (zip)」は選ばないでください）。zip を右クリック →「プロパティ」→「許可する」にチェック →「OK」としてから展開し、展開したフォルダの `初回セットアップ.bat`、`起動.bat` の順に開きます。
- 画面写真入りの説明（入れ方・毎日の使い方・設定・困ったときの対処）は、**[取扱説明書（PDF）](docs/manual/取扱説明書.pdf)**（または [Markdown 版](docs/manual/取扱説明書.md)）にあります。

## 動作環境

- **OS**: Windows 10 / 11
- **Python**: 3.10 以降
- **ブラウザ**: Microsoft Edge（動作確認は Edge のみ。他のブラウザは未確認）
- サーバーにするPCは1台だけです。他のPCやタブレットは、ブラウザで開くだけで使えます。

## セットアップ

**ふつうは `初回セットアップ.bat` をダブルクリックするだけで済みます**（インターネット接続が必要です）。

1. PC に Python 3.10 以降が入っていない場合は、https://www.python.org/ から入れます。インストールの最初の画面で「Add Python to PATH」に**必ずチェック**を入れてください
2. `初回セットアップ.bat` をダブルクリックします
3. 「セットアップが完了しました」と出たら、黒い窓を閉じます

コマンドで行う場合は、アプリのフォルダで次を実行します。

```cmd
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

使う部品の版は、安全確認をした版に固定してあります（`requirements.txt`）。版を勝手に変えないでください。

| パッケージ | 用途 |
|---|---|
| Flask | Webサーバー |
| waitress | 本番用サーバー |
| jpholiday | 日本の祝日判定 |
| pytest | テスト実行 |

## 起動方法

**ふつうは `起動.bat` をダブルクリックします。**

1. 黒い窓が開き、掲示板が動き出すのを待ってから（最大60秒）、いつもの Edge で掲示板が開きます。全画面にしたいときは Edge で `F11` を押します
2. **この黒い窓は閉じないでください**（閉じると掲示板が止まります）
3. 終了するときは、Edge を閉じ、黒い窓をクリックして `Ctrl + C` を押します。入力した内容は止めても消えず、次の起動で続きから表示されます

コマンドで起動する場合は、アプリのフォルダで `.venv\Scripts\python.exe app.py` を実行します。

### 起動後の黒い窓

```
デジタル掲示板を起動します
  このPCで開く: http://localhost:5100
  他のPCで開く: http://（数字のアドレス）:5100
  管理者キー: <管理者キー>（他のPCから全端末共通の設定を変えるときに使います）
  終了するときは Ctrl + C を押してください
```

- 既定のポートは **5100** です。使われていたら **5101〜5109** を順に試し、最初に空いていたものを使います。そのときは「注意: ポート 5100 は使用中のため、ポート 5101 で起動します」と出ます。実際に使うポートは、アプリのフォルダの `server_port.txt` に書かれ、`起動.bat` はこれを読んで開く先を決めます
- すでに掲示板が動いているときに `起動.bat` をもう一度開くと、新しくは起動せず、「すでに起動しています: http://localhost:（ポート）」と出て、動いている掲示板が開きます
- 5100〜5109 がすべて使用中だと起動できません（エラーが出ます）
- 「管理者キー」は [他のPCから使う](#他のpcから使う) で使います

### PC起動時に自動で始める（案・未設定）

Windows の「スタートアップ」フォルダ（`Win + R` で `shell:startup`）に、`起動.bat` のショートカットを入れる方法が簡単です。Windows にログインしたあとに始まります。**実際にやるときは、PCを再起動して動くことを確かめてください（未確認です）。**

## 画面構成と使い方

### 画面の見かた

- 欄をタップ（クリック）すると、登録済みの候補から選べます。保存ボタンはありません。連絡事項だけは自由に入力でき、常に3行分の高さで表示し、増えたら枠の中でスクロールします（編集中の「＋ 連絡事項を追加」で増やせます。4行以上のときだけ✕で消せます）
- 本日の作業予定は、前日の内容を引き継いで始まります。▲▼で並べ替え、✕で削除すると下の行が上に詰まります。所属・会社名は `data/companies/` に置いた会社のファイル、工事件名は `data/constructions/` に置いた工事件名のファイルから選びます。責任者を選ぶ前に、所属・会社名を選びます（その会社の責任者だけが候補に出て、名前の下に内線・外線が出ます。会社を変えると責任者は空になります）。作業内容は、その行の工事件名のファイルに書いてあるものだけが候補に出ます（今週の休日出勤予定も同じ。工事件名が空の行や、作業内容が1つも書かれていない工事件名の行では、全部から選べます）。工事件名を変えて、いまの作業内容がそれに合わないときは、作業内容が自動で空になります
- 今週の休日出勤予定は、月曜〜日曜の週ごとに切り替わります。今週の休日（土日・祝日・会社の休日）の行が、掲示板を最初に表示したときに1日1行ずつ自動で作られます（日付だけが入り、ほかの欄は空で「―」と表示します）。「―」の欄をタップすると、通常どおり候補から選べ、「クリア」で「―」に戻ります。消した行は戻りません。同じ日に入力のある行が1つでもあると、その日の「―」だけの行は表示しません（入力のある行をすべて消すと、また「―」の行が出ます）。「＋ 行を追加」で行を足すときの日付は、今週の休日から選びます。本日の作業予定の空欄は、これまでどおり空白のままです
- 作業ジャンルをチェックすると、そのジャンルの災害事例PDFが順に自動再生されます。タップや左右のスワイプで手動送りもできます。災害事例の枠は A4 横の形（縦横比 297:210）で、枠の大きさは変わりません。ジャンルの欄は3行まで表示し（それ以上は欄の中でスクロール）、ジャンルが2〜3行に折り返すと、その分だけ休日出勤予定の表が低くなります（1920×1080 の画面で、1行なら表に約4〜5行、2行以上なら約3行見えます）
- 右下のボタンで、フォルダに入れた文書（PDF）を閲覧できます。文書ボタンの上に、別のページを開く**リンクボタン**（最大2つ）を置くこともできます
- 画面の一番下に、お知らせが右から左へ流れます。スリープ画面・設定・文書の閲覧のときは、その下に隠れます
- **スリープ画面**: 夜間（既定 18:00〜翌 08:00）は、時計だけのスリープ画面になります（Windows 本体のスリープとは別です）。触ると戻り、戻したあと一定時間（既定300秒）なにも触れないと、まだ夜間なら再びスリープ画面になります。開始と終了を同じ時刻にすると、スリープ画面は出ません

### 編集ボタンと配色（この端末だけの設定）

歯車の設定は2つに分かれています。「この端末だけ」は、そのパソコン（ブラウザ）ごとに保存されます。モニタで変えても、他のPCの設定は変わりません。

- **編集ボタン**: 「なし」（初期値）は、いつでも入力できます。「あり」にすると、普段は閲覧のみになり、「編集」を押したときだけ入力できます。しばらく操作しないと自動で閲覧に戻ります。誤操作を防ぐためのもので、暗証番号はありません
- **配色**: 明るい／暗い

`起動.bat` はいつもの Edge で開くので、選んだ値はこのPCの Edge に保存されます。閲覧データを消すと初期値に戻るので、モニタのPCでは `config.json` の `default_edit_button` と `default_theme` に書いておくと、保存が無いときも決めた状態で始まります。

### 災害事例と文書のPDFを置く場所

どちらのフォルダも、無ければ起動時に自動で作られます。

- **災害事例（`accident_cases`）**: **ファイル名の先頭が作業ジャンル名**です。「ジャンル名_内容.pdf」の形にします（例 `溶接作業_事例A.pdf`）。複数のジャンルに当てはまる事例は `＋` でつなぎます（例 `溶接作業＋高所作業_事例A.pdf`。どれか1つでもチェックされていれば再生され、重複しては出ません）。`data/genres.csv` に無いジャンル名のファイルは再生されません。再生順は `genres.csv` の並び順、同じジャンルの中はファイル名順です。複数ページのPDFは1ページずつ表示します。災害事例のPDFは **横向きのA4** で作るのがおすすめです（枠は A4 横の形なので、上下の余白なしにぴったり収まります）。縦向きのA4でも全体が見えますが、小さくなり、左右に余白が出ます。ジャンルのタグとページ番号は、枠のすぐ上（タグは左、ページ番号は右）に出るので、資料の上には何も重ならず、A4 の全体が見えます（枠の下の端に、次へ進むまでの進み具合を示す細い線が出るだけです）
- **文書（`documents`）**: 右下の文書ボタンに対応するフォルダです。既定では `documents/doc1`〜`doc3` の3つで、「文書1」〜「文書3」のボタンになります。見せたいPDFを対応するフォルダに入れます。ボタンの数・名前・フォルダの場所は、歯車の設定で変えられます。文書を開いたまま一定時間（既定120秒）なにも操作しないと、掲示板に戻ります

### お知らせ（画面の一番下に流れる文字）

文章は、`telop` フォルダ（無ければ起動時に自動で作られます）に置いた**テキストファイル**に書きます。メモ帳で書いて、拡張子を `.txt` にして保存するだけです。

- フォルダの中の `.txt` をすべて、ファイル名の順に読みます。**1行が1件**で、空の行は無視されます
- 文章の一部を `"` で囲むと、そこだけオレンジ色の丸い札（バッジ）になります。例: `"安全"今月は保護具の着用を徹底しましょう`。全角の `＂` や、カーブした `“` `”` も使えます。対になっていない引用符は、ふつうの文字のまま表示されます
- 文字コードは、UTF-8・Shift-JIS（ANSI）・UTF-16（メモ帳の「Unicode」）のどれでも読めます
- 流す件数は全部で200件まで、1件は500文字まで（超えた分は切れます）。1MB を超える大きなファイルは読まれません
- ファイルを保存すると、数秒で画面に反映されます。1件も無いときは「お知らせはありません」と流れます
- 流れる速さとフォルダは、歯車の「テロップ速度」「テロップフォルダ」で変えます

**設備点検システム（equipment-inspection）と同じお知らせを使うとき**: そちらのサイネージが読むフォルダ（`.txt` を置く場所。PDF と同じフォルダ）のパスを、歯車の「テロップフォルダ」に入れて「保存して適用」を押します。こちらが読むのは `.txt` だけです。2つのアプリが同じファイルを読むので、片方のために直した行は、もう片方にも出ます（別々にしたいときはフォルダを分けます）。

お知らせの文章は、このリポジトリには同梱していません（現場ごとの内容なので、自分で置いてください）。

### リンクボタン（別のページを掲示板の中で開く）

文書ボタンの上に、別のページを開くボタンを**最大2つ**置けます（例: 設備点検システム `http://サーバーPC名:5000/`）。歯車の「全端末共通」→「リンクボタン」に、名前とアドレスを入れて「保存して適用」を押します。

- 押すと、掲示板の上に枠が開き、その中にリンク先のページが出ます。枠の上に「掲示板へ戻る」と「開けないときは別のタブで開く」があります（リンク先が枠の中での表示を許していないときは、別のタブで開きます）
- 開いたまま「最大滞在」（既定300秒）が近づくと、「あと30秒で戻ります」と「続ける」が出ます。「続ける」を押すと、最大滞在の最初から数え直します。押さないと、自動で掲示板に戻ります
- 開いている間は、スリープ画面には入りません。閉じると、中のページは止まります（入力途中の内容は残りません）。災害事例の自動再生は、開いている間は止まり、閉じると再開します
- アドレスは `http://` か `https://` で始まるものだけです（空白、`ユーザー名:パスワード@` 付き、500文字超は使えません）
- リンク先のページは、**それを開くPCのブラウザから**見えている必要があります。「サーバーPC名」「IPアドレス」で書いてください（`localhost` は、開いたPC自身のことになります）。設備点検システムは、初期設定ではサーバーPC自身からしか開けないので、他のPCから使うときは、設備点検システム側の設定（`server.host` を `0.0.0.0`）が必要です
- 設備点検システムの実機での表示は未確認です（[未確認のこと](#未確認のこと)）

## 登録リスト（CSV）の編集

`data` フォルダの CSV を、Excel やメモ帳で編集します。保存すると、画面は数秒で反映されます（掲示板を止める必要はありません）。文字コードは **UTF-8** で保存してください（Excel の「CSV UTF-8（コンマ区切り）」）。

**会社と工事件名は、「1つのファイルが1つの項目」**です。ファイル名（`.csv` を除いた部分）が、そのまま会社名・工事件名になります。ほかのリスト（作業ジャンル・時刻・会社の休日）は、これまでどおり1つのファイルです。

| 場所 | 列 | 内容 |
|---|---|---|
| `data/companies/（会社名）.csv` | `責任者,内線,外線` | **会社ごとに1ファイル。** ファイル名が会社名（所属・会社名。休日出勤の「氏名・会社名」にも使います）。1行目は見出し、2行目からが責任者（1人1行）。内線・外線は、空欄でも、列ごと省いても構いません |
| `data/constructions/（工事件名）.csv` | `作業内容` | **工事件名ごとに1ファイル。** ファイル名が工事件名。1列だけで、その工事件名で選べる作業内容を1行に1つずつ書きます |
| `data/genres.csv` | `name` | 作業ジャンル（並び順もこの順）。名前を変えたら、災害事例PDFのファイル名の先頭も同じに直してください |
| `data/times.csv` | `time` | 就業予定の時刻の候補（無ければ 6:00〜22:00 の30分刻みで自動作成） |
| `data/custom_holidays.csv` | `date,name` | 会社の休日（例 `2026-12-29,年末休業`）。祝日は自動で判定します。場所は設定で変えられます（下記の `custom_holidays_file`） |

以前の版で使っていた、会社・責任者・作業内容・工事件名を1つずつのファイルにまとめた登録リストは、もう使いません。`data` に残っていても読まれません。

**会社のファイルの例**（`data/companies/見本電機.csv`。Excel では次のように見えます）:

| | A | B | C |
|---|---|---|---|
| 1 | 責任者 | 内線 | 外線 |
| 2 | 田中 | | 03-0000-0001 |
| 3 | 小林 | 2345 | 03-0000-0002 |

メモ帳で開くと、次のとおりです。

```
責任者,内線,外線
田中,,03-0000-0001
小林,2345,03-0000-0002
```

**工事件名のファイルの例**（`data/constructions/配管工事.csv`）:

```
作業内容
組み立て作業
搬入作業
メンテナンス作業
```

**会社を足す・直す・消す（会社の協力会社が CSV を送ってくれるとき）**

- 協力会社に、上のような CSV（見出し `責任者,内線,外線`）を、**「会社名.csv」というファイル名**で作って送ってもらいます。それを `data/companies/` に入れるだけで、会社が登録されます（別の「会社の一覧」はありません）。数秒で、すべての画面の候補に会社が出ます。再起動は要りません
- 同じ名前のファイルを上書きすれば、責任者の一覧が新しくなります。ファイルを消すと、その会社は選べなくなります（すでに画面に入っている行の文字は、そのまま残ります。責任者の内線・外線は出なくなります）
- 見出しだけのファイル（責任者を書いていない会社）も、会社としては選べます（社内の班など）。サンプルの `山田.csv` がその例で、責任者の欄を押すと「この会社の責任者は登録されていません」と出ます
- 工事件名も同じです。`data/constructions/` に「工事件名.csv」を入れると、工事件名の候補に出ます
- `_雛形.csv` は、コピーして使うひな形です（先頭が `_` のファイルは読み込まれません）。コピーして、名前を会社名・工事件名に変えて、中身を書き換えます

**並び順**: 候補は、ファイル名の順に並びます。数字は数の大きさで比べるので、`1班`、`2班`、`10班` の順になります。それ以外は文字コードの順で、ひらがな・カタカナ・漢字は五十音順にはなりません（サンプルでは 1班、2班、サンプル建設、山田、見本電機 の順です）。順番を変えたいときは、ファイル名の先頭に数字を付けます（その数字も会社名・工事件名の一部になります）。

**決まり**

- **作業内容の候補**: 行の工事件名を選ぶと、その工事件名のファイルに書いた作業内容だけが、ファイルに書いた順に並びます（本日の作業予定・今週の休日出勤予定の両方）。工事件名が空の行や、作業内容を1つも書いていない工事件名（見出しだけのファイル）の行では、**全部のファイルの作業内容**（重なりを除いたもの）から選べます。作業内容を書き忘れても、入力できなくなることはありません
- 工事件名を変えたとき、いまの作業内容が新しい工事件名で選べないものなら、作業内容は自動で空になります（会社を変えると責任者が空になるのと同じです）。同じ工事件名を選び直しても、作業内容は残ります。選べない作業内容を無理に入れようとすると、「この工事件名では選べない作業内容です」と断られます
- **読み込まれないもの**: ファイル名が `~$` で始まるもの（Excel が開いている間に作る一時ファイル）、`.` や `_` で始まるもの、拡張子が `.csv` でないもの、フォルダの中のフォルダ
- **ファイル名に使えない文字**: Windows のきまりで、ファイル名には `\ / : * ? " < > |` が使えません。これらの文字を含む会社名・工事件名は、ファイルを作れないので登録できません（別の書き方にします）。また、名前は書いた文字のとおりに扱います（全角と半角は別の文字です。同じ作業内容は、どのファイルでも同じ文字で書きます）
- 同じファイルの中で、同じ責任者の名前や同じ作業内容を2回書いたときは、最初の1つだけを使います（責任者は名前だけで比べるので、内線が違っても同じ人として扱います）
- 空の行は無視されます。1行目の見出しは、日本語の `責任者`・`内線`・`外線`・`作業内容` のほか、古い英語の見出し（`leader_name`・`ext`・`outside`・`name`）も読めます。列の並びは自由です。見出しの前後の空白は無視されます

**書き間違えたとき（画面の上の黄色い警告）**

- UTF-8 でないファイル（ふつうの「CSV」で保存したもの）: 「○○.csv を読めません。Excelで『CSV UTF-8（コンマ区切り）』として保存し直してください」。そのファイルの会社・工事件名は、選べません
- 必要な見出し（会社なら `責任者`、工事件名なら `作業内容`）が無い・ファイルが空: 「○○.csv に列がありません: 責任者」「○○.csv が空です。1行目に見出し（責任者）が必要です」。そのファイルは使われません
- 同じファイルの中での重なり: 「data/companies に、同じ責任者が2回書かれたファイルがあります（2回目以降は使いません。最初の例: …）」（工事件名では「同じ作業内容が2回書かれた…」。何か所あっても警告は1フォルダにつき1つです）
- フォルダが無い: 「data/companies フォルダがありません」。会社・工事件名は1つも選べません
- 直して保存すると、警告は数秒で消えます

同梱している中身は架空のサンプル（サンプル工業(株)・見本電機・配管工事など）です。自社の内容に書き換えてください。以前から使っている `board.db` は、起動したときに必要な欄が自動で足されます（入力済みの内容はそのまま残ります）。

**会社の休日ファイルを設備点検システムと共通にする**: 設備点検システムの `data/custom_holidays.csv` と形式（`date,name`）は同じです。歯車の「会社の休日ファイル」にそのパスを入れると、こちらは読むだけで、書き換えません。ファイルを直すと、13秒ほどで画面に反映されます。

## 設定の変更

### 画面上から変更する方法

画面の右上の歯車ボタンを押します。設定の窓は長いので、窓の中でスクロールします。いちばん下にバージョンが出ます。

**「全端末共通」**は、掲示板を動かしているPCの `config.json` に保存され、**どの画面から変えても全部の画面に反映**されます。「保存して適用」を押すと、掲示板を止めて起動し直さなくてもすぐ変わります。

| 項目 | 内容 |
|---|---|
| 管理者キー | 別のPCから保存するときだけ出る欄（[他のPCから使う](#他のpcから使う)） |
| 会社名（右上に表示） | 1〜100文字。空欄・改行は保存できません |
| テロップフォルダ | お知らせの `.txt` のフォルダ。空欄は `telop`。相対パスか `D:/…`・`//server/share/…`。`..` は使えません |
| テロップ速度 | 20〜500（px/秒） |
| 会社の休日ファイル | 空欄は `data/custom_holidays.csv`。`..` は使えません |
| スリープ開始／終了 | `18:00` のような時刻。同じ時刻にするとスリープしません |
| 操作なしでスリープに戻る（秒） | スリープ画面から戻したあと、操作が無いと再びスリープに戻る秒数（1〜86400） |
| 災害事例の表示秒数 | 1枚（1ページ）を映す秒数（1〜86400） |
| 文書の操作なし戻り（秒） | 文書閲覧で操作が無いと掲示板へ戻る秒数（1〜86400） |
| 編集の自動終了（秒） | 編集ボタン「あり」で、操作が無いと閲覧に戻る秒数（1〜86400） |
| 文書掲示 | ボタン数（1〜5）と、ラベル・フォルダパス。ボタン数より後ろの行は灰色で使われません。使う行は、ラベルとフォルダパスの両方が必須です。無いフォルダは自動で作ります（作れない場所のときは、保存はされ、「作れませんでした」と知らせが出ます） |
| リンクボタン（最大2つ） | 名前とアドレス。名前もアドレスも空の行は使いません。片方だけは保存できません。「最大滞在（秒）」は60〜3600 |

入力に誤りがあるときは、窓の下に赤字で「⚠ 理由」が出て、何も保存されません。保存すると、`config.json` のうち上の項目だけが書き換わり、手で書いた他の項目はそのまま残ります。`config.json` が無いときは新しく作られます。手で書いた `config.json` に書き間違いがあるときは、「config.json に書き間違いがあります。直してから保存してください」と出て**保存されません**（ファイルはそのまま残ります）。メモ帳で直してから、もう一度保存してください。

**バックアップとログ**: 保存のたびに、変更前の `config.json` が `backups/config_日時.json` に写されます（新しい5件だけ残ります。中身が変わらない保存では作りません。`config.json` が無かったとき最初の保存でも作りません）。戻したいときは、掲示板を止めて、控えを `config.json` という名前でアプリのフォルダにコピーします。`logs/app.log` には、起動・警告・設定の保存・エラーが記録されます（1MB を超えると古い順に `app.log.1`〜`app.log.5` に世代交代します。連絡事項などの文章や管理者キーは書きません）。

### config.json の設定項目

無くても既定で動きます。変えたい項目があるときだけ、アプリのフォルダに `config.json` を作って書きます。**手で書き換えたときは、掲示板を止めてもう一度起動してください**（歯車から保存した項目は、起動し直さなくても反映されます）。

- フォルダの場所は、`/` で区切るか（例 `D:/掲示板/災害事例`）、`\\` のように2つ重ねます。`\` を1つだけ書くと JSON の決まりでエラーになります
- 書き間違いがあった項目は、その項目だけ既定の値を使って起動し、画面の上に黄色い警告が出ます（例「config.json の accident_seconds が正しくありません（15秒を使います）」）。直して、起動し直してください
- 秒数は 1 以上 86400 以下の数字です。フォルダの場所・休日ファイルは260文字まで、会社名やボタンのラベルは100文字までです
- 既存の `config.json` に `"standby": {"end": "07:30"}` と書いてある場合は、その値のまま動きます（既定が 08:00 に変わっただけです）

例（会社名と災害事例の表示秒数だけ変える）:

```json
{
  "company_name": "株式会社〇〇",
  "accident_seconds": 20
}
```

| 項目 | 既定 | 内容 |
|---|---|---|
| `company_name` | サンプル工業(株) | 画面右上の会社名。歯車でも変えられます |
| `default_theme` | light | 配色の初期値（`light` / `dark`）。そのPCで選んだ配色があれば、そちらが優先 |
| `default_edit_button` | off | 編集ボタンの初期値（`on` / `off`）。そのPCで選んだ値があれば、そちらが優先 |
| `accident_folder` | accident_cases | 災害事例PDFのフォルダ |
| `accident_seconds` | 15 | 災害事例1枚の表示秒数。歯車でも変えられます |
| `documents.buttons` | 文書1〜3 | 文書ボタン（最大5つ。`label` と `folder`）。歯車でも変えられます |
| `documents.idle_return_seconds` | 120 | 文書閲覧で操作が無いと掲示板へ戻る秒数。歯車でも変えられます |
| `telop.folder` | telop | お知らせの `.txt` のフォルダ。歯車でも変えられます |
| `telop.speed` | 100 | お知らせの速さ（20〜500の整数）。歯車でも変えられます |
| `edit_lock_seconds` | 60 | 編集中に操作が無いと閲覧へ戻る秒数。歯車でも変えられます |
| `standby.start` / `standby.end` | 18:00 / 08:00 | スリープ画面にする時間帯（項目名は `standby` のまま）。歯車でも変えられます |
| `standby.wake_idle_seconds` | 300 | スリープ画面から戻したあと、操作が無いとスリープに戻る秒数。歯車でも変えられます |
| `server.host` | 0.0.0.0 | 待ち受けるアドレス。`127.0.0.1` にすると、このPC自身からしか開けません（`:` を含む値は使えません）。起動時に1回だけ読むので、変えたら起動し直します |
| `server.port` | 5100 | 基本のポート（1024〜65526）。使用中なら +9 まで順に試します。起動し直しが必要です |
| `custom_holidays_file` | data/custom_holidays.csv | 会社の休日ファイルの場所。歯車でも変えられます |
| `links.items` | （なし） | リンクボタン（最大2つ。`label` と `url`）。歯車でも変えられます |
| `links.max_stay_seconds` | 300 | リンクを開いたまま自動で戻るまでの秒数（60〜3600）。歯車でも変えられます |

## 他のPCから使う

社内LANの他のPC（やブラウザの使えるタブレット）から、同じ画面を見たり入力したりできます。

1. サーバーPCで `起動.bat` を起動し、黒い窓の「他のPCで開く」のアドレス（`http://（数字のアドレス）:5100`）を控えます。合わないときは、サーバーPCで `ipconfig` を実行し、「IPv4 アドレス」の数字を使います
2. 他のPCのブラウザで、そのアドレスを開きます
3. 初めて起動したとき、Windows が「ファイアウォールでアクセスを許可しますか？」と聞いてきます。社内LANで使う場合は、「プライベートネットワーク」を許可します（許可しないと、他のPCから開けません。サーバーPC自身では開けます）
4. 他のPCから開けないときは、サーバーPCのファイアウォールで基本のポート（既定 5100、TCP）の受け付けが許可されているか確認します。ファイアウォールの許可と、他のPCのブックマークは、基本のポートの番号に合わせて作ります。ポートが自動で切り替わった（5101〜）ときは、黒い窓に出た番号で開き直してください

**管理者キー**: 他のPCから「全端末共通」の設定を**保存**するときは、管理者キーが必要です。キーは、初回の起動で `admin_key.txt` に自動で作られ、起動のたびに黒い窓に表示されます。他のPCで歯車を開くと「管理者キー」の欄が出るので、入れてから「保存して適用」を押します（同じブラウザのタブでは、一度うまくいくと覚えます。半角英数字のみ）。サーバーPC自身で `localhost` や `127.0.0.1` を使って開いているときは、キーは要りません。

- 毎日の入力（作業予定・連絡事項・ジャンルなど）にキーは要りません。ログインはありません
- 設定の**保存**だけがキーで守られます。設定の内容の表示は、誰でもできます
- `admin_key.txt` を読めるのは、アプリのフォルダを開ける人です。**キーは他人に教えないでください**（`.gitignore` で、Git には入りません）。作り直すときは、掲示板を止めて `admin_key.txt` を消し、起動し直します
- 社内LANの中だけで使ってください。インターネットから見える場所には置かないでください
- 文書やお知らせのフォルダにネットワークの場所（`\\サーバー名\…`）を指定すると、このPCがそこへ接続しに行きます。社内の信頼できる場所だけを指定してください

## バックアップと引っ越し

掲示板に入力した内容は `data/board.db` に入っています。バックアップするときは、**掲示板を止めてから**、次をまとめてコピーします。

## トラブルシューティング

### 起動時に「ポートが使用中」と表示される

他のアプリが 5100 番を使っているときは、自動で 5101〜5109 のどれかで起動します。黒い窓に出る URL を確認し、他のPCからは、その番号で開き直してください（ファイアウォールの許可と他のPCのブックマークは、基本のポート 5100 で作ってあるものなので、切り替わったときは、その番号でも開けるか確認が要ります）。5100〜5109 がすべて使用中のときは、起動できません。他のアプリを終了するか、`config.json` の `server.port` を変えてください。`起動.bat` をすでに起動している状態でもう一度開いたときは、「すでに起動しています」と出て、動いている掲示板が開きます（ほぼ同時に2回押すと、2つ起動することがあります。そのときは片方を `Ctrl + C` で止めます）。

### 災害事例が出ない

- 作業ジャンルにチェックが付いているか確認します。「該当する災害事例がありません」と出るときは、`accident_cases` にそのジャンルのPDFが無い状態です
- ファイル名が `ジャンル名_内容.pdf` の形で、ジャンル名が `data/genres.csv` と同じ文字か、拡張子が `.pdf` か確認します

### テロップが流れない

- `telop` フォルダ（または設定したフォルダ）に `.txt` があるか、1MB を超えていないか確認します。拡張子が `.txt.txt` になっていることもあります

### CSVを編集したのに反映されない

- 文字コードが **UTF-8** か確認します。Excel では「CSV UTF-8（コンマ区切り）」で保存します
- 掲示板の再起動は不要です。数秒で反映されます（会社の休日ファイルは13秒ほど）。1行目の見出しを消していないかも確認してください
- 画面の上に黄色い警告が出ていないか確認します。出ているときは、書かれているファイルを直します

### 会社・工事件名が選べない（候補に出ない）

- `data/companies/`（会社）、`data/constructions/`（工事件名）に、その名前のファイルがあるか確認します。ファイル名が会社名・工事件名です。拡張子が `.csv` か（`.csv.csv` や `.txt` になっていないか）、名前が `_`・`.`・`~$` で始まっていないか、全角・半角が同じかも確認します
- 1行目の見出し（会社は `責任者`、工事件名は `作業内容`）があるか、UTF-8 で保存したかを確認します。違うときは、画面の上に黄色い警告（「○○.csv を読めません…」「○○.csv に列がありません…」）が出て、そのファイルは使われません
- 会社名や工事件名に `\ / : * ? " < > |` が入っていると、ファイルを作れません

### 責任者の候補に出ない

- 会社のファイル（`data/companies/（会社名）.csv`）の2行目以降に、その人が書いてあるか確認します。見出しだけのファイルの会社は、責任者が登録されていません（「この会社の責任者は登録されていません」と出ます）

### 作業内容の候補に、選びたいものが出ない

- 候補は、その行の工事件名のファイル（`data/constructions/（工事件名）.csv`）に書いた作業内容だけです。選びたい作業内容を、そのファイルの2行目以降に足します。工事件名が空の行や、作業内容を1つも書いていない工事件名の行は、全部のファイルの作業内容から選べます
- 作業内容の文字が、全角・半角の違いや打ち間違いで合っていないこともあります。画面の上に黄色い警告が出ていれば、そこに書かれたファイルを直します
- 工事件名を変えたら作業内容が空になった、というのは、新しい工事件名では選べない作業内容だったためで、故障ではありません。選び直します

### 設定が保存できない

- 窓の下の赤字のとおりに直します
- 別のPCからで「管理者キーが必要です」「管理者キーが違います」と出るときは、サーバーPCの黒い窓か `admin_key.txt` のキーを入れます。サーバーPCで開いていて同じ表示が出るときは、`http://localhost:ポート` で開き直してください（PC名やIPアドレスで開くと、他のPC扱いになります）
- 「config.json に書き間違いがあります」と出るときは、メモ帳で直します。ログ（`logs/app.log`）にも理由が残ります

- ピンチ（つまんで拡大）と、スワイプ（災害事例の手動送り）の操作感
- 70インチモニタ（フルHDか4K）での見え方。お知らせと設定の窓の文字の大きさ、設定の窓の収まり、流れる文字のなめらかさ
- 時刻の入力欄（スリープ開始・終了）の表示が、そのPCの設定で12時間表記になるか
- `起動.bat` で開く通常の Edge で、歯車の設定（編集ボタン・配色）が再起動後も残るか
- PC起動時の自動起動
- `起動.bat`: 開発の確認用に、別の場所へコピーして、通常の起動・2回目の起動・ポート使用中の切り替えを実行し、動くことを確認しました。これ以外（実機のモニタPC、他の設定のPC）では確かめていません。`初回セットアップ.bat` は、開発中に別の場所へコピーして実行し、成功を確認しました（その後の版では再実行していません）
- リンクボタンを、設備点検システムの実際の画面で開いたときの表示・操作（枠の中で表示を許さないページは「別のタブで開く」を使います）。説明書の写真は、掲示板自身のアドレスを開いて撮ったものです
- 管理者キーを、実際の2台目のPCから使う操作（キーの確認は、自動テストでサーバー側のみ）
- 他のPCの画面にも、設定の変更が3秒ほどで届くか（自動テストでサーバー側のみ）
- `D:/文書` のようなドライブ指定や `//server/share/文書` のようなネットワークの共有フォルダを、実機で指定して使えるか
