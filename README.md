# デジタル掲示板

バージョン 0.1.0

工場などの「本日の作業内容」ホワイトボードの代わりに、大型のタッチモニタ（と社内LANの他のPC）で、本日の作業予定・連絡事項・今週の休日出勤予定・災害事例の自動再生・文書閲覧を行うWebアプリです。

## 入手のしかたと説明書

- **使うだけの方**は、このページ右側の「Releases」から、いちばん新しい版の `digital-bulletin-board-v0.1.0.zip` をダウンロードします（「Source code (zip)」は選ばないでください）。zip を右クリック →「プロパティ」→「許可する」にチェック →「OK」としてから展開し、展開したフォルダの `初回セットアップ.bat`、`起動.bat` の順に開きます。
- くわしい使い方は、**[取扱説明書（PDF）](docs/manual/取扱説明書.pdf)**（または [Markdown 版](docs/manual/取扱説明書.md)）を見てください。画面写真つきで、入れ方・毎日の使い方・設定・困ったときの対処まで説明しています。

## 使い方

### 1. 初回セットアップ（最初の1回だけ）

1. パソコンに Python 3.10 以降が入っていない場合は、https://www.python.org/ から入れます。インストールの最初の画面で「Add Python to PATH」に**必ずチェック**を入れてください
2. `初回セットアップ.bat` をダブルクリックします（インターネット接続が必要です）
3. 「セットアップが完了しました」と出たら、黒い窓を閉じます

使う部品（Flask・waitress・jpholiday・pytest）の版は、安全確認をした版に固定してあります（`requirements.txt`）。版を勝手に変えないでください。

### 2. 起動

1. `起動.bat` をダブルクリックします。黒い窓が開き、掲示板が動き出すのを待ってから（最大60秒）、いつもの Edge の画面で掲示板が開きます（全画面にしたいときは Edge で `F11` を押します）
2. **この黒い窓は閉じないでください**（閉じると掲示板が止まります）
3. 黒い窓には「他のPCで開く」というアドレスが出ます。他のPCからは、そのアドレスをブラウザに入力して開きます（ポートは 5100 固定です）

### 3. 終了

1. Edge は、ふつうに画面右上の × で閉じます（全画面のときは `F11` で戻してから）
2. 黒い窓をクリックして `Ctrl + C` を押すと、掲示板が止まります。その後は窓を閉じて構いません

入力した内容は、止めても消えません。次に起動したときに続きから表示されます。

## 画面の操作

- 欄をタップすると、登録済みの候補から選べます（工事件名も、`data/constructions.csv` に登録した中から選びます）。連絡事項だけは自由に入力でき、常に3行分の高さで表示し、増えたら枠の中でスクロールします（編集中の「＋ 連絡事項を追加」で増やせます。4行以上のときだけ✕で消せます）
- 本日の作業予定は、前日の内容を引き継いで始まります。▲▼で並べ替え、✕で削除すると下の行が上に詰まります
- 今週の休日出勤予定は、月曜〜日曜の週ごとに、月曜になると空欄になります。日付は今週の休日（土日・祝日・会社の休日）から選びます
- 作業ジャンルをチェックすると、そのジャンルの災害事例PDFが順に自動再生されます。タップや左右のスワイプで手動送りもできます
- 右下のボタンで、フォルダに入れた文書（PDF）を閲覧できます
- 画面の一番下に、お知らせが右から左へ流れます（「お知らせ」の置き方は下の章）。待機画面・設定・文書の閲覧のときは、その下に隠れます
- 夜間（既定 18:00〜翌7:30）は時計だけの待機画面になります。触ると戻ります

### 設定メニュー（右上の歯車ボタン）

設定メニューは2つに分かれています。

**「この端末だけ」**（そのパソコン（ブラウザ）ごとに保存されます。モニタで変えても、他のPCの設定は変わりません）

- **編集ボタン**: 「なし」（初期値。`config.json` の `default_edit_button` で変えられます）は、いつでも入力できます。「あり」にすると、普段は閲覧のみになり、「編集」を押したときだけ入力できます。しばらく操作しないと自動で閲覧に戻ります。誤操作を防ぐためのもので、暗証番号はありません（歯車から「なし」に戻せます）
- **配色**: 明るい／暗い

**「全端末共通」**（掲示板を動かしているPCの `config.json` に保存され、**どの画面から変えても全部の画面に反映**されます。「保存して適用」を押すと、掲示板を止めて起動し直さなくてもすぐ変わります。操作は、姉妹アプリの設備点検（equipment-inspection）の設定と同じです）

- **文書掲示（文書ボタン）**: 「ボタン数（1〜5）」を数字で入れます。その下に、「ラベル 1〜5」と「フォルダパス」の欄が5行いつも出ています。ボタン数より後ろの行は灰色になって使われません（入力した文字は残り、ボタン数を増やすとまた使えます）。使う行は、ラベルとフォルダパスの両方が必須で、空のままだと「ラベル 2 を入力してください」のように行を示して保存されません。フォルダは、アプリのフォルダからの場所（例 `documents/doc1`）か、`D:/文書` や `//server/share/文書` のようにすべて書いた場所を指定します。無いフォルダは自動で作ります（作れない場所のときは、保存はされ、「作れませんでした」と知らせが出ます）
- **会社名（右上に表示）**: 画面の右上に出る会社名です（1〜100文字。空欄・改行などは保存できません）。歯車 → 「全端末共通」 → 「会社名」に入れて「保存して適用」を押すと、`config.json` の `company_name` に保存され、全部の画面に数秒で反映されます。`config.json` を手で書き換えて起動し直す方法でも変えられます
- **テロップフォルダ**: お知らせの `.txt` を置くフォルダ。空欄にすると、アプリのフォルダの中の `telop` フォルダになります（相対パスか、`D:/…` や `//server/share/…` のようにすべて書いた場所。`..` は使えません）。姉妹アプリの equipment-inspection と共通にする方法は、下の「お知らせ」の章を見てください
- **テロップ速度**: 画面下のお知らせが流れる速さ（px/秒、20〜500。既定 100）

入力に誤りがあるときは、フォームの下に赤字で「⚠ 理由」が出て、何も保存されません（フォルダの場所に `..` を含めることはできません）。保存すると、`config.json` のうち上の項目だけが書き換わり、手で書いた他の項目（会社名・`documents.idle_return_seconds` など）はそのまま残ります。`config.json` がまだ無いときは、保存すると新しく作られます。

手で書いた `config.json` に書き間違い（JSON の決まりに合わない書き方）があるときは、「config.json に書き間違いがあります。直してから保存してください」と出て、**保存されません**（あなたが書いた他の設定を消さないためです。ファイルはそのまま残ります）。`config.json` をメモ帳で直してから、もう一度保存してください。他のプログラムが `config.json` を開いていて読めないときも、保存されず、その旨が出ます。

**注意（セキュリティ）**: この掲示板にはログインがないため、社内LANにつながった**どの端末からでも**この「全端末共通」の設定を変えられます（文書ボタンの名前と、見せるフォルダの場所を変えられます）。文書として配信されるのは、設定したフォルダの中のPDFだけで、フォルダの一覧にあるファイル名しか開けません。それでも、LANに知らない人がつながる環境では使わないでください。フォルダにネットワークの場所（`\\サーバー名\…`）を指定すると、このPCがそこへ接続しに行きます。社内の信頼できる場所だけを指定してください。

#### モニタのPCで「編集ボタンあり」を最初から有効にしたいとき

`起動.bat` は、いつもの Edge（普段のプロフィール）で開くので、歯車で選んだ「編集ボタン」と「配色」は、このPCのEdgeに保存され、次回も残ります。ブラウザの閲覧データを消したときなどに「なし」に戻るので、モニタのPCでは、`config.json` に次のように書いておくと、保存が無いときは毎回「あり」で始まります。

```json
{
  "default_edit_button": "on"
}
```

歯車で選んだ値がそのパソコンに残っているときは、そちらが優先されます。

## 選択肢の登録（Excelで編集）

`data` フォルダの CSV を、Excel やメモ帳で編集します。保存すると、画面は数秒で反映されます。文字コードは **UTF-8（BOM付き）** で保存してください（Excel の「CSV UTF-8（コンマ区切り）」）。

| ファイル | 列 | 内容 |
|---|---|---|
| `companies.csv` | `name` | 所属・会社名／氏名（休日出勤の氏名・会社名にも使います） |
| `leaders.csv` | `company,leader_name,ext,outside` | 責任者。会社名ごとに登録し、内線（`ext`）・外線（`outside`）はどちらか一方でも構いません |
| `works.csv` | `name` | 作業内容 |
| `constructions.csv` | `name` | 工事件名（本日の作業予定の一番左と、今週の休日出勤予定の「日付」の右隣の欄に出ます。空欄のままでも構いません） |
| `genres.csv` | `name` | 作業ジャンル（並び順もこの順）。追加・名前の変更もここで行います。名前を変えたら、災害事例PDFのファイル名の先頭も同じに直してください |
| `times.csv` | `time` | 就業予定の時刻の候補（無ければ 6:00〜22:00 の30分刻みで自動作成） |
| `custom_holidays.csv` | `date,name` | 会社の休日（例 `2026-12-29,年末休業`）。祝日は自動で判定します |

同梱している中身は架空のサンプル（サンプル工業(株) など）です。自社の内容に書き換えてください。`constructions.csv` が無いと、画面の上に黄色い警告が出て、工事件名は選べません。

以前から使っている `board.db` は、起動したときに工事件名の欄が自動で追加されます（入力済みの内容はそのまま残り、工事件名だけが空欄になります）。

## 災害事例と文書のPDFを置く場所

どちらのフォルダも、無ければ起動時に自動で作られます。

### 災害事例（`accident_cases` フォルダ）

- **ファイル名の先頭が作業ジャンル名**です。「ジャンル名_内容.pdf」の形にします。例: `溶接作業_事例A.pdf`
- 複数のジャンルに当てはまる事例は、ジャンル名を `＋` でつなぎます。例: `溶接作業＋高所作業_事例A.pdf`。どれか1つでもチェックされていれば再生され、重複しては出ません
- `data/genres.csv` に無いジャンル名のファイルは再生されません
- 再生順は、`genres.csv` の並び順、同じジャンルの中はファイル名順です。PDFが複数ページなら、1ページずつ順に表示します
- 横向きのA4で作ると、枠にぴったり収まります

### 文書（`documents` フォルダ）

右下の文書ボタンに対応するフォルダです。既定では `documents/doc1`、`documents/doc2`、`documents/doc3` の3つで、それぞれ「文書1」「文書2」「文書3」のボタンになります。見せたいPDFを、対応するフォルダに入れてください。ボタンの数・名前・フォルダの場所は、歯車の設定メニュー（「全端末共通」の「文書掲示」）で変えられます。

## お知らせ（画面の一番下に流れる文字）

画面の一番下に、「お知らせ」の文字が右から左へ流れます。文章は、`telop` フォルダ（アプリのフォルダの中。無ければ起動時に自動で作られます）に置いた**テキストファイル**に書きます。Excel は要りません。メモ帳で書いて、拡張子を `.txt` にして保存するだけです。

- フォルダの中の `.txt` ファイルをすべて、ファイル名の順に読みます。ファイルはいくつ置いても構いません
- **1行が1件のお知らせ**です。空の行は無視されます。件と件のあいだは、広くあけて流れます
- 文章の一部を `"` で囲むと、そこだけオレンジ色の丸い札（バッジ）になります。例: `"安全"今月は保護具の着用を徹底しましょう`。半角の `"` のほか、全角の `＂` や、カーブした `“` `”` も使えます（開く側と閉じる側が違う種類でも構いません。例: `“重要”`）。閉じ忘れなど、対になっていない引用符は、ふつうの文字のまま表示されます
- 文字コードは、メモ帳の標準の UTF-8 でも、Shift-JIS（ANSI）でも、UTF-16（メモ帳の「Unicode」）でも、読めます
- 流す件数は全部で200件までです（超えた分は流れません）。1件は500文字までで、超えた分は切れます。1MB を超える大きなファイルは読まれません
- ファイルを保存すると、数秒で画面に反映されます（画面を操作する必要はありません）
- お知らせが1件も無いときは「お知らせはありません」と流れます
- 流れる速さと、お知らせを置くフォルダは、設定メニュー（全端末共通）の「テロップ速度」「テロップフォルダ」で変えます（`config.json` の `telop.speed` / `telop.folder` に保存されます。保存すると、起動し直さなくてもすぐ変わります）

**equipment-inspection と同じお知らせを使うとき**

- equipment-inspection のサイネージは、設定したフォルダの中の `.txt` を1行1件で読みます（形式は上と同じです）。そのフォルダ（テキストファイルを置いている場所。PDF と同じフォルダです）のパスを、設定メニューの「テロップフォルダ」に入れて「保存して適用」を押します
- こちらが読むのは、そのフォルダの中の `.txt` だけです。PDF やほかの種類のファイルは無視されます。文字コードは UTF-8・Shift-JIS・UTF-16 のどれでも読めます
- **注意**: 2つのアプリが同じファイルを読むので、片方のために直した行は、もう片方にも出ます。別々にしたいときは、フォルダを分けてください
- フォルダが他のPC（ネットワーク）にある場合は、上の「注意（セキュリティ）」のとおり、信頼できる場所だけを指定してください

お知らせの文章は、このリポジトリには同梱していません（現場ごとの内容なので、`telop` フォルダに自分で置いてください）。

## 設定（config.json）

無くても既定で動きます。変えたい項目があるときだけ、アプリのフォルダに `config.json` を作って書きます。変更したら、掲示板を止めてもう一度起動してください（**文書ボタンとお知らせの速度だけは、歯車の設定メニューから保存すると、起動し直さなくてもすぐ変わります**。保存すると `config.json` が自動で作られる／書き換えられます）。

- フォルダの場所を書くときは、`/` で区切るか（例 `D:/掲示板/災害事例`）、`\\` のように2つ重ねてください（例 `D:\\掲示板\\災害事例`）。`\` を1つだけ書くと JSON の決まりでエラーになります
- 書き間違いがあった項目は、その項目だけ既定の値を使って起動し、画面の上に黄色い警告が出ます（例「config.json の accident_seconds が正しくありません（15秒を使います）」）。警告が出たら `config.json` を直して、掲示板を起動し直してください
- フォルダが作れない場所（存在しないドライブなど）を指定したときも、起動は続き、警告が出ます
- 秒数は 1 以上 86400 以下の数字で書きます
- フォルダの場所（災害事例・文書ボタン・お知らせ）は260文字まで、会社名やボタンのラベルなどの文字は100文字までです。設定メニューから保存するときも同じです

例（会社名と災害事例の表示秒数だけ変える）:

```json
{
  "company_name": "株式会社〇〇",
  "accident_seconds": 20
}
```

| 項目 | 既定 | 内容 |
|---|---|---|
| `company_name` | サンプル工業(株) | 画面右上の会社名（1〜100文字）。設定メニューからも変えられます |
| `default_edit_button` | off | 編集ボタンの初期値（`on` か `off`）。そのパソコンで歯車から選んだ値があれば、そちらが優先されます |
| `default_theme` | light | 配色の初期値（`light` か `dark`）。そのパソコンで選んだ配色があれば、そちらが優先されます |
| `accident_folder` | accident_cases | 災害事例PDFのフォルダ |
| `accident_seconds` | 15 | 災害事例1枚の表示秒数 |
| `documents.buttons` | 文書1〜3 | 文書ボタン（最大5つ。ボタンごとに `label` と `folder` を書く）。設定メニューからも変えられます |
| `telop.speed` | 100 | お知らせの流れる速さ（px/秒、20〜500の整数）。設定メニューからも変えられます |
| `telop.folder` | telop | お知らせの `.txt` を置くフォルダ |
| `documents.idle_return_seconds` | 120 | 文書閲覧で操作が無いと掲示板へ戻る秒数 |
| `edit_lock_seconds` | 60 | 「編集」ボタンで編集中、操作が無いと閲覧へ戻る秒数 |
| `standby.start` / `standby.end` | 18:00 / 07:30 | 待機画面にする時間帯 |
| `standby.wake_idle_seconds` | 300 | 待機画面から戻したあと、操作が無いと再び待機に戻る秒数 |

## 他のPCから開く（社内LAN）

- 掲示板を動かしているPC（サーバーPC）の起動中に、他のPCのブラウザで、黒い窓に出る「他のPCで開く」のアドレス（`http://（数字のアドレス）:5100`）を入力します
- 初めて起動したとき、Windows が「ファイアウォールでアクセスを許可しますか？」と聞いてくることがあります。社内LANで使う場合は、「プライベートネットワーク」を許可してください。許可しないと、他のPCから開けません（サーバーPC自身では開けます）
- 他のPCから開けないときは、サーバーPCのファイアウォールで 5100 番（TCP）の受け付けが許可されているか確認してください
- ログイン認証はありません。社内LANの中だけで使ってください

## PC起動時に自動で始める（案・未設定）

今は設定していません。やる場合の考え方だけ書いておきます。

- Windows の「スタートアップ」フォルダ（`Win + R` で `shell:startup` と入力すると開きます）に、`起動.bat` のショートカットを入れる方法が、いちばん簡単です
- この方法では、Windows にログインしたあとに始まります。ログイン前から動かしたい場合は、別の方法（タスクスケジューラなど）が必要です
- 実際にやるときは、必ずPCを再起動して動くことを確かめてください（未確認です）

## バックアップ

掲示板に入力した内容は、`data` フォルダの `board.db` に入っています。バックアップするときは、次をまとめてコピーしてください。

- `data/board.db`
- `data/board.db-wal` と `data/board.db-shm`（掲示板が動いている間だけ存在する補助ファイルです）

確実に取るには、掲示板を止めてからコピーします。あわせて、CSV（`data/*.csv`）、`config.json`、`accident_cases` と `documents` のPDFもコピーしておくと、別のPCに引っ越せます。

## 未確認のこと（実機で確かめる必要があります）

次の点は、開発中の環境では確かめられていません。実際のモニタで試して、おかしければ教えてください。

- Windows のタッチキーボードが、連絡事項の入力時に出るか
- ピンチ（つまんで拡大）と、スワイプ（災害事例の手動送り）の操作感
- 70インチモニタの解像度（フルHDか4Kか）での見え方
- `起動.bat` で開く通常の Edge で、歯車の設定（編集ボタン・配色）が再起動後も残るか（残らない場合は `default_edit_button` と `default_theme` を `config.json` に書きます）
- お知らせ（下の流れる文字）と設定メニュー（全端末共通）の実際の見え方・操作感。特に、70インチのタッチモニタでの文字の大きさ、フルHD／4Kでの設定メニューの収まり、明るい／暗い配色の見やすさ、流れる文字がなめらかか
- 設定メニューの「保存」で、他のPCの画面にも3秒ほどで文書ボタンの変更が届くか（開発中は自動テストでサーバー側のみ確認）
- `D:/文書` のようなドライブ指定や `//server/share/文書` のようなネットワークの共有フォルダを、実機で文書フォルダに指定して開けるか
- PC起動時の自動起動
- `起動.bat` と `初回セットアップ.bat` の実際の動作。開発中に、`初回セットアップ.bat`（別の場所へコピーして実行）は成功を、`起動.bat`（全画面で開く旧版）は掲示板が起動して Edge が開くことを確かめました。**いまの `起動.bat`（いつもの Edge で開く形）は、実機で実行していません**（文字の中身とファイル形式までは確認済み）。`起動.bat` の「掲示板が動き出すまで待つ」部分は Windows 11 付属の `curl.exe` を使います
