# ホワイトボード機能 設計書

日付: 2026-11-02 / 対象: デジタル掲示板（v0.3.0 に入れる予定。未公開）

## 目的
掲示板の画面を、タッチパネルで文字や絵を描ける真っ白なホワイトボードに切り替えられるようにする。描いたものは、決められたフォルダにカラーのPDFとして保存する。PDFを背景に読み込んで、その上に書き込むこともできる。

## 決定事項（ユーザーとの合意）
- 描いたものは固定（選択・移動・拡大縮小はしない）。
- 道具: ペン・直線・矢印・四角・丸・文字・消しゴム、色（8色）、太さ（3段階）、元に戻す・やり直し・全部消す。
- 背景PDF: 設定で決めた専用フォルダのPDFだけを一覧に出す。選ぶときに1ページを指定し、そのページだけを背景にする。
- 保存: 保存ボタンでPDF（1ページ・カラー）を保存先フォルダへ。ファイル名は日付時刻（`2026-11-02_21-30-00.pdf`）。
- 操作なしの時間が来たら、30秒前に警告し、時間が来たら自動保存して掲示板に戻る（ファイル名は `…_自動保存.pdf`）。白紙なら保存しないで戻る。
- 保存先に書き込めないときはエラーを画面に出し、描いたものは消さない（自動保存で失敗したときは戻らず画面に残す）。「保存先を試す」ボタンは付けない。

## 画面と操作
- 文書ボタンの並びに「ホワイトボード」ボタンを足す。編集ロック中でも押せる（`isEditable()` の制限をかけない）。
- 押すと全画面の描画画面（オーバーレイ）になる。上部に道具バー。
- 文字: 描画画面を押した場所に小さな入力窓を出し、確定で描く。
- 描いたものは背景PDFとは別の層に持つ。消しゴムで背景は消えない。
- 保存したら「保存しました」と出し、描画画面に残る。
- 描画画面を開いている間はスリープ画面に入らない。

## 構成
- フロント: 新規 `static/js/whiteboard.js`（描画・道具・操作なし監視）。Pointer Events で描画する。背景PDFは同梱の pdf.js（`static/pdfjs`）で1ページをcanvasに描く。既存の `documents.js`（操作なしで戻る）、`links.js`（30秒前の警告）、`picker.js` の作りに合わせる。
- 保存: 背景+描画を重ねたcanvasをJPEGにして、サーバーに送る。サーバーが標準ライブラリだけで1ページのPDFに包む（JPEG をそのまま画像として埋め込む）。新しいライブラリは入れない。
- サーバー（`app.py` に追加、PDF作成は新規 `whiteboard.py`）:
  - `GET /api/whiteboard/pdfs` 背景用フォルダのPDF一覧
  - `GET /api/whiteboard/pdfs/<名前>` 背景PDFの中身（フォルダ外・`..` は拒否）
  - `POST /api/whiteboard/save` JPEGを受け取り、PDFにして保存先へ書く。成功・失敗を返す
- 書き込みはサーバーを動かしているPCが行う。表示側PCに書き込み権限は要らない。保存先はサーバーから見た場所で指定する（`\\サーバー\共有\…` も可。ドライブ文字は避ける）。
- 書き込みは一時ファイルに書いてから名前を付け替える（途中で切れた壊れたPDFを残さない）。同じ名前があれば連番を付ける。

## 設定（歯車の「全端末共通」に3項目）
| 項目 | config.json のキー | 初期値 |
|---|---|---|
| ホワイトボードの保存フォルダ | `whiteboard_save_folder` | `whiteboard` |
| 背景用のPDFフォルダ | `whiteboard_pdf_folder` | `whiteboard_pdfs` |
| 操作なし戻り（秒） | `whiteboard_idle_seconds` | 180 |

既存の `config.py` の `take()` / `clean_admin_settings` / `save_admin_settings` の作りに合わせる。秒数は範囲を決めて検証する（30〜3600）。変更は `_changed_groups` の記録に出す。

## エラーの扱い
- 保存先に書けない（権限なし・ネットワーク切断・フォルダなし）: 「保存できませんでした（理由）」を画面に出す。描画は残す。
- 背景用フォルダが無い・PDFが無い: 一覧に「PDFがありません」と出す。
- 背景PDFが壊れている: 読み込めない旨を出して、白紙のまま続ける。

## テスト
- 自動テスト: PDFの作り（先頭 `%PDF`、ページ数1、画像の埋め込み、xrefの位置が正しい）、保存先の書き込み・連番・失敗時の応答、背景PDFのパス検証（`..`・フォルダ外）、設定の保存と検証、自動保存の白紙判定。
- 実画面: Edge ヘッドレスでペン・図形・文字・元に戻す・保存・操作なし戻りを実行して確認。保存したPDFを開いて見た目を確かめる。
- 確認できないこと: 実物のタッチパネルでの操作、実際のネットワーク共有への書き込み。

## 対象外（作らない）
描いたものの選択・移動、複数ページ、表示側PCへの保存、「保存先を試す」ボタン。
